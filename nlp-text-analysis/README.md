# 📊 文本分析小工具 · 词频统计 + 词云

数字人文（DH）入门练习项目：读入一段文字，自动分词、统计高频词，并生成柱状图和词云。

## 这个项目演示了什么

这是数字人文技能表里 **"🟡 强烈加分"** 的第一项 —— **NLP（自然语言处理）** 的最小实践：

- 🈶 **中文分词**（用 `jieba`，解决"中文没有空格"的问题）
- 🔢 **词频统计**（用 `collections.Counter`）
- 📈 **数据可视化**（用 `matplotlib` 画柱状图）
- ☁️ **词云生成**（用 `wordcloud`，词越大出现越频繁）

## 快速开始

```bash
# 1. 安装依赖（只需一次）
py -3.10 -m pip install -r requirements.txt

# 2. 运行分析（分析默认样例）
py -3.10 analyze.py

# 3. 分析你自己的文字
py -3.10 analyze.py 我的文章.txt
```

## 输出结果

运行后会在 `output/` 文件夹生成三个文件：

| 文件 | 说明 |
| --- | --- |
| `top_words.csv` | 前 50 个高频词，可用 Excel 打开 |
| `frequency.png` | 高频词柱状图 |
| `wordcloud.png` | 词云图 |

## 怎么把它变成你自己的作品

1. **替换文本**：把你的文章、笔记、随笔存成 `.txt` 文件（UTF-8 编码），替换 `sample_text.txt`
2. **调停用词**：编辑 `analyze.py` 里的 `STOPWORDS`，加入你觉得没意义的词
3. **改图表样式**：修改 `draw_bar_chart` 里的颜色、字体、尺寸
4. **换分析对象**：分析一本小说的对话、一份历史档案的转写、你的批注合集

## 技术栈

- Python 3.10
- jieba（中文分词）
- matplotlib（图表）
- wordcloud（词云）

## 进阶方向（等你熟悉后可以挑战）

- 用 `pandas` 做更复杂的数据处理
- 用 TF-IDF 找出"某篇文章特有的关键词"
- 用 `spaCy` 做命名实体识别（提取人名/地名/机构）
